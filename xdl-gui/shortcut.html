一键获取 XDL 快捷指令

点击下载后，在 Safari 下载列表中打开“XDL下载.shortcut”即可添加到 Apple「快捷指令」App。

当前服务器地址（安装引导第 1 题粘贴）
  1. 下载并添加：点击上方按钮下载安装包，在 Safari 右上角（或底部）点击下载图标打开并点添加快捷指令。
  2. 完成导入提问：按屏幕提示填入服务器地址（可点上方一键复制）和你的 Shortcut API Token（无密码模式可留空）。
  3. 在 X 中直接分享使用：浏览推文或博主主页时点 分享 → XDL 下载，弹出视频时长限制框并自动派发到服务器（引用转发会自动询问单条或原作者全部媒体）。
