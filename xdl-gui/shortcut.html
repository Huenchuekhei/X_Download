一键获取 XDL 快捷指令

点击下载后，在 Safari 下载列表中打开“XDL下载.shortcut”即可添加到 Apple「快捷指令」App。

当前服务器地址（添加到快捷指令后粘贴到第 1 个文本框）
  1. 下载并添加：点击上方按钮下载安装包，在 Safari 下载列表中打开“XDL下载.shortcut”并直接点添加快捷指令（已移除易在 iOS 18.5+ / iOS 26 卡死的导入提问页）。
  2. 粘贴地址与 Token：在「快捷指令」App 点 XDL下载 右上角 … 编辑，将上方服务器地址（含 http:// 或 https://）和控制台的 Shortcut API Token（无密码模式留空）粘贴到顶部前两个「文本」框，点完成。
  3. 在 X 中直接分享使用：浏览推文或博主主页时点 分享 → XDL 下载，弹出视频时长限制框并自动派发到服务器（引用转发会自动询问单条或原作者全部媒体）。
